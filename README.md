# 学习兴趣组

欢迎来到学习兴趣组课程仓库。本仓库按照学期整理学习路线、示例代码和实践资料。

## 学期导航

- [上学期：Python 基础](./README_上学期.md)
- [下学期：动手学深度学习](./README_下学期.md)

## 内容说明

- `上学期/`：八周课程，每周一份综合讲义（`第01周_…` 到 `第08周_…`，含讲解与完整示例代码），外加 `Anaconda基础.md`（课前资料，不占课时）。
- `每周项目/`：每周练习和分享会资料。
- `游戏/`：Python 游戏项目。
- `资料/`：课程参考资料。
- `pytorch/`：下学期深度学习课程 Notebook 和配套资源。

建议先完成上学期的 Python 基础学习，再进入下学期的深度学习课程。

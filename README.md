## 内容说明

- `上学期/`：八周课程。`讲义/`（第 01–08 周讲义）、`代码/`（各周示范代码，按周命名）、`前置准备/`（Anaconda 配置教程，不占课时）。
- `每周项目/`：每周练习和分享会资料。
- `游戏/`：Python 游戏项目。
- `资料/`：课程参考资料。
- `pytorch/`：下学期深度学习课程 Notebook 和配套资源。

建议先完成上学期的 Python 基础学习，再进入下学期的深度学习课程。

## 📚 学习路线规划

### 第一阶段：Python基础入门（7-11周）

每周我们都会安排一些训练项目给大家练手，希望大家能跟上我们的节奏，坚持到最后总会有收获

#### 第7周 - 环境搭建
- **核心任务**
  - 安装Anaconda/Miniconda
  - 配置国内镜像源（清华/阿里云）
  - 安装VS Code及相关Python插件
  - 创建第一个Python虚拟环境
  - 掌握基础命令行操作

#### 第8周 - 编程基础学习
- **核心语法**
  - 变量、数据类型、运算符
  - 条件语句（if-elif-else）
  - 循环结构（for、while）
  - 基础输入输出
- **实战练习**
  - 简易计算器
  - 猜数字游戏

#### 第9周 - 数据结构
- **核心内容**
  - 列表、元组、字典、集合
  - 函数定义与参数传递
  - 模块导入与使用
- **实战项目**
  - 学生成绩管理系统
  - 通讯录管理程序

#### 第10周 - 文件操作
- **重点技能**
  - 文本文件读写操作
  - JSON数据格式处理
  - 异常捕获与处理
  - 调试技巧学习
- **实战项目**
  - 日志分析器
  - 配置文件解析器

#### 第11周 - 面向对象编程
- **核心概念**
  - 类与对象
  - 封装、继承、多态
  - 特殊方法（__init__等）
- **综合项目**
  - 银行账户管理系统
  - 简易游戏角色设计

### 第二阶段：NumPy库探索（12-13周）

#### 第12周 - 数据科学第一步
- **核心学习**
  - 创建NumPy数组
  - 数组索引与切片
  - 数组形状操作
  - 基础统计函数
- **实战练习**
  - 图像数据模拟处理
  - 成绩数据统计分析

#### 第13周 - 矩阵运算
- **进阶技能**
  - 矩阵运算与线性代数
  - 广播机制
  - 随机数生成
  - 性能优化技巧
- **实战项目**
  - 实现PCA降维算法
  - 物理运动轨迹模拟

### 第三阶段：PyTorch框架初体验（14-15周）

#### 第14周 - 深度学习入门
- **核心概念**
  - 张量（Tensor）创建与操作
  - 自动求导机制
  - 数据集加载与预处理
- **实战练习**
  - 手写数字识别（MNIST）
  - 自定义数据集构建

#### 第15周 - 神经网络搭建
- **深度学习进阶**
  - 全连接神经网络
  - 激活函数选择
  - 损失函数与优化器
  - 模型训练与验证
- **实战项目**
  - 房价预测模型
  - 服装分类器（Fashion-MNIST）

### 第四阶段：机器学习趣味基础（16周）

#### 第16周 - AI实战入门
- **核心概念**
  - 了解机器学习基本流程
  - 掌握数据预处理方法
  - 学习模型训练与评估
- **趣味项目大集合** 🎉
  - 📊 **数据可视化分析** - 用图表讲故事
  - 🎯 **简易推荐系统** - 基于用户相似度的电影推荐
  - 📈 **线性回归实战** - 预测考试成绩
  - 🔍 **KNN分类器** - 手写数字识别进阶

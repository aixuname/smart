## 一、列表：一排有顺序的盒子

列表用方括号 `[]`，里面可以放任意类型，**有顺序、可修改**。

```python
scores = [90, 85, 77, 92, 60]
names = ["小明", "小红", "小刚"]
mixed = [1, "二", 3.0, True]      # 类型可以混，但不推荐
empty = []
```

### 1. 取值和切片

和字符串完全一样，从 0 开始：

```python
print(scores[0])      # 90
print(scores[-1])     # 60
print(scores[1:3])    # [85, 77]
print(len(scores))    # 5
```

### 2. 增删改

```python
scores = [90, 85, 77]

scores.append(92)         # 末尾追加      [90, 85, 77, 92]
scores.insert(1, 100)     # 在 1 号位置插  [90, 100, 85, 77, 92]
scores[0] = 95            # 直接改        [95, 100, 85, 77, 92]
scores.remove(85)         # 删掉值 85（第一个匹配）
last = scores.pop()       # 删掉并返回最后一个
del scores[0]             # 删掉 0 号位置
print(scores)
```

### 3. 排序与统计

```python
scores = [90, 85, 77, 92, 60]

scores.sort()                  # 原地从小到大：[60, 77, 85, 90, 92]
scores.sort(reverse=True)      # 从大到小
print(len(scores))             # 5    个数
print(sum(scores))             # 404  总和
print(max(scores), min(scores))# 92 60
print(sum(scores) / len(scores))  # 平均分 80.8
```

> `sort()` 会**改掉原列表**，`sorted()` 会返回新列表、不动原来的。初学先用 `sort()` 就行，记得它会改原数据。

### 4. 判断在不在里面

```python
names = ["小明", "小红"]
print("小明" in names)      # True
print("小王" in names)      # False
```

## 二、字典：按名字查找

字典用花括号 `{}`，存的是「键 → 值」的对应关系。适合**按某个名字找数据**。

```python
student = {
    "name": "小明",
    "age": 18,
    "score": 92
}
```

### 1. 取值（重点）

```python
print(student["name"])          # 小明
print(student.get("name"))      # 小明
print(student.get("height"))    # None    键不存在时返回 None，不报错
print(student["height"])        # ❌ KeyError 直接崩
```

> **建议：不确定键在不在，就用 `get()`。** 这是新手最常见的崩溃之一。

### 2. 增删改

```python
student["age"] = 19             # 改（键存在就是改）
student["city"] = "北京"         # 增（键不存在就是加）
del student["city"]             # 删
print(student)
```

### 3. 遍历字典

```python
student = {"name": "小明", "age": 18, "score": 92}

for key in student:                     # 默认遍历键
    print(key)

for key, value in student.items():      # 同时拿键和值（最常用）
    print(key, "=", value)

print(list(student.keys()))             # ['name', 'age', 'score']
print(list(student.values()))           # ['小明', 18, 92]
```

## 三、元组和集合（认识即可）

```python
point = (3, 5)          # 元组：用小括号，创建后不能改
print(point[0])         # 3

print(tags)             # {'python', 'ai'}
```

## 四、条件判断：让程序做选择

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 75:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

三个必须记住的点：

1. **冒号不能少**：`if 条件:`
2. **缩进就是语法**：属于 `if` 的代码必须缩进 4 个空格，退出来就表示「if 结束了」。
3. **从上往下判断**，命中一个就不再往下走。

### 条件可以组合

```python
age = 20
is_student = True

if age >= 18 and is_student:
    print("成年学生")

if age < 12 or age > 60:
    print("不在青年区间")

if "小明" in ["小明", "小红"]:
    print("找到小明")
```

### 空值判断

```python
name = input("请输入名字：")

if name:            # 空字符串算 False，有内容算 True
    print("你好，" + name)
else:
    print("你没有输入名字")
```

## 五、循环

### 1. `for` + 列表：把每个元素过一遍

```python
names = ["小明", "小红", "小刚"]

for name in names:
    print(f"你好，{name}")
```

### 2. `for` + `range`：重复 N 次

```python
for i in range(5):        # 0 1 2 3 4
    print(i)

for i in range(1, 6):     # 1 2 3 4 5
    print(i)

for i in range(1, 10, 2): # 1 3 5 7 9（步长 2）
    print(i)
```

> `range(1, 6)` **不包含 6**，和切片一样「含头不含尾」。

### 3. `while`：条件为真就一直转

```python
count = 0
while count < 3:
    print("第", count + 1, "次")
    count += 1      # ⚠️ 忘了这句就是死循环
```

### 4. `break` 和 `continue`

```python
for i in range(10):
    if i == 3:
        break       # 直接跳出整个循环
    print(i)        # 0 1 2

for i in range(5):
    if i == 2:
        continue    # 跳过这一次，继续下一次
    print(i)        # 0 1 3 4
```

### 5. 遍历时的下标

```python
names = ["小明", "小红", "小刚"]

for i, name in enumerate(names):
    print(i, name)      # 0 小明 / 1 小红 / 2 小刚
```

## 六、本周产出：词频统计

需求：给一句话，统计每个词出现几次，按次数从多到少输出。

```python
text = "python is easy and python is fun and python is powerful"

# 第 1 步：按空格拆成单词列表
words = text.split()
print(words)

# 第 2 步：统计次数
counts = {}
for word in words:
    if word in counts:
        counts[word] += 1     # 已经有了，加 1
    else:
        counts[word] = 1      # 第一次见，记为 1

# 第 3 步：按次数排序输出
for word, count in counts.items():
    print(f"{word}: {count} 次")
```

输出：

```
python: 3 次
is: 3 次
easy: 1 次
and: 2 次
fun: 1 次
powerful: 1 次
```

**这个程序就是本周的核心产出。** 先照着敲通，再自己改成「统计一段中文的每个字出现几次」。

## 七、常见错误对照表

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `IndexError: list index out of range` | 列表没这么长 | `len()` 检查，最后一个下标是 `len-1` |
| `KeyError: 'xxx'` | 字典里没这个键 | 用 `.get("xxx")`，或先 `in` 判断 |
| `IndentationError: expected an indented block` | `if`/`for` 下面没缩进 | 加 4 个空格 |
| `IndentationError: unindent does not match` | 空格和 Tab 混用 | 全部改成空格 |
| 程序卡住不动 | `while` 死循环，忘了改条件 | 检查循环里有没有让条件变化 |
| `for i in range(1, 10)` 循环不到 10 | `range` 含头不含尾 | 改成 `range(1, 11)` |
| `TypeError: 'int' object is not iterable` | 对数字用了 `for` | 用 `range(n)` |
| 边遍历列表边删除，结果不对 | 边迭代边改长度 | 复制一份再遍历：`for x in lst[:]` |

## 一、列表：一排有顺序的盒子

列表用方括号 `[]`，里面可以放任意类型，**有顺序、可修改**。

```python
scores = [90, 85, 77, 92, 60]
names = ["小明", "小红", "小刚"]
mixed = [1, "二", 3.0, True]      # 类型可以混，但不推荐
empty = []
```

### 1. 取值和切片

和字符串完全一样，从 0 开始：

```python
print(scores[0])      # 90
print(scores[-1])     # 60
print(scores[1:3])    # [85, 77]
print(len(scores))    # 5
```

### 2. 增删改

```python
scores = [90, 85, 77]

# append() 只在末尾追加一个元素，会直接修改原列表
scores.append(92)         # [90, 85, 77, 92]

# insert(位置, 值) 在指定位置插入，后面的元素向右移动
scores.insert(1, 100)     # [90, 100, 85, 77, 92]

# 通过下标重新赋值，修改第 0 个元素
scores[0] = 95            # [95, 100, 85, 77, 92]

# remove(值) 删除第一个匹配的值；找不到会报 ValueError
scores.remove(85)         # [95, 100, 77, 92]

# pop() 删除并返回最后一个元素，所以 last 得到 92
last = scores.pop()       # scores 变成 [95, 100, 77]

# del 按下标删除；这里删除第 0 个元素 95
del scores[0]             # [100, 77]

print("最终列表：", scores)
print("pop 删除的元素：", last)
```

### 3. 排序与统计

```python
scores = [90, 85, 77, 92, 60]

scores.sort()                  # 原地从小到大：[60, 77, 85, 90, 92]
scores.sort(reverse=True)      # 从大到小
print(len(scores))             # 5    个数
print(sum(scores))             # 404  总和
print(max(scores), min(scores))# 92 60
print(sum(scores) / len(scores))  # 平均分 80.8
```

> `sort()` 会**改掉原列表**，而且返回值是 `None`；`sorted()` 会返回新列表、不动原来的。不要写 `new_scores = scores.sort()`，否则 `new_scores` 会是 `None`。

```python
scores = [90, 60, 85]

sorted_scores = sorted(scores)  # 创建排序后的新列表
print(scores)                   # [90, 60, 85]，原列表没变
print(sorted_scores)            # [60, 85, 90]
```

### 4. 判断在不在里面

```python
names = ["小明", "小红"]
print("小明" in names)      # True
print("小王" in names)      # False
```

## 二、字典：按名字查找

字典用花括号 `{}`，存的是「键 → 值」的对应关系。适合**按某个名字找数据**。

```python
student = {
    "name": "小明",
    "age": 18,
    "score": 92
}
```

### 1. 取值（重点）

```python
print(student["name"])          # 小明
print(student.get("name"))      # 小明
print(student.get("height"))    # None    键不存在时返回 None，不报错
# print(student["height"])      # 故意取消注释才会触发 KeyError
```

> **建议：不确定键在不在，就用 `get()`。** 这是新手最常见的崩溃之一。

### 2. 增删改

```python
student["age"] = 19             # 改（键存在就是改）
student["city"] = "北京"         # 增（键不存在就是加）
del student["city"]             # 删
print(student)
```

### 3. 遍历字典

```python
student = {"name": "小明", "age": 18, "score": 92}

for key in student:                     # 默认遍历键
    print(key)

for key, value in student.items():      # 同时拿键和值（最常用）
    print(key, "=", value)

print(list(student.keys()))             # ['name', 'age', 'score']
print(list(student.values()))           # ['小明', 18, 92]
```

## 三、元组和集合（认识即可）

```python
point = (3, 5)          # 元组：用小括号，创建后不能改
print(point[0])         # 3

tags = {"python", "ai", "python"}   # 集合：自动去重，无序
print(tags)             # {'python', 'ai'}
```

这两个这周**会用就行，不深究**。后面 NumPy、Pandas 里基本用不到元组和集合。

### 容器是否可修改

| 类型 | 有顺序 | 可修改 | 是否允许重复 | 典型用途 |
| --- | --- | --- | --- | --- |
| 列表 `list` | 是 | 是 | 是 | 一组按顺序排列的数据 |
| 字典 `dict` | 按插入顺序保存 | 是 | 键不能重复 | 根据名字查数据 |
| 元组 `tuple` | 是 | 否 | 是 | 不希望被改动的一组值 |
| 集合 `set` | 不依赖顺序 | 是 | 否 | 去重、集合运算 |

### 一个容易忽略的坑：两个变量可能指向同一个列表

```python
scores = [90, 85, 77]
backup = scores          # 不是复制数据，只是给同一个列表再起一个名字

scores.append(100)
print(backup)            # [90, 85, 77, 100]，backup 也“跟着变了”
```

如果希望得到独立副本，可以用 `copy()`：

```python
scores = [90, 85, 77]
backup = scores.copy()   # 创建新的列表

scores.append(100)
print(scores)            # [90, 85, 77, 100]
print(backup)            # [90, 85, 77]
```

## 四、条件判断：让程序做选择

```python
score = 85

# 条件从严格到宽松排列。Python 从上往下检查，命中后就跳过其余分支。
if score >= 90:
    print("优秀")
elif score >= 75:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

三个必须记住的点：

1. **冒号不能少**：`if 条件:`
2. **缩进就是语法**：属于 `if` 的代码必须缩进 4 个空格，退出来就表示「if 结束了」。
3. **从上往下判断**，命中一个就不再往下走。

可以用下面的跟踪表理解 `score = 85`：

| 检查顺序 | 条件 | 结果 | 下一步 |
| ---: | --- | --- | --- |
| 1 | `85 >= 90` | False | 继续检查 |
| 2 | `85 >= 75` | True | 输出“良好”，结束整个分支 |
| 3 | `85 >= 60` | 不再检查 | — |

### 条件可以组合

```python
age = 20
is_student = True

if age >= 18 and is_student:
    print("成年学生")

if age < 12 or age > 60:
    print("不在青年区间")

if "小明" in ["小明", "小红"]:
    print("找到小明")
```

### 空值判断

```python
name = input("请输入名字：")

if name:            # 空字符串算 False，有内容算 True
    print("你好，" + name)
else:
    print("你没有输入名字")
```

## 五、循环

### 1. `for` + 列表：把每个元素过一遍

```python
names = ["小明", "小红", "小刚"]

# 第 1 轮 name 是“小明”，第 2 轮是“小红”，第 3 轮是“小刚”
for name in names:
    print(f"你好，{name}")
```

循环变量 `name` 不是整个列表，它每一轮只代表当前取到的一个元素。可以临时打印轮次帮助理解：

```python
names = ["小明", "小红", "小刚"]

for index, name in enumerate(names, start=1):
    print(f"第 {index} 轮开始，当前 name = {name}")
    print(f"你好，{name}")
```

### 2. `for` + `range`：重复 N 次

```python
for i in range(5):        # 0 1 2 3 4
    print(i)

for i in range(1, 6):     # 1 2 3 4 5
    print(i)

for i in range(1, 10, 2): # 1 3 5 7 9（步长 2）
    print(i)
```

> `range(1, 6)` **不包含 6**，和切片一样「含头不含尾」。

### 3. `while`：条件为真就一直转

```python
count = 0
while count < 3:
    print("第", count + 1, "次")
    count += 1      # ⚠️ 忘了这句就是死循环
```

### 4. `break` 和 `continue`

```python
for i in range(10):
    if i == 3:
        break       # 直接跳出整个循环
    print(i)        # 0 1 2

for i in range(5):
    if i == 2:
        continue    # 跳过这一次，继续下一次
    print(i)        # 0 1 3 4
```

### 5. 遍历时的下标

```python
names = ["小明", "小红", "小刚"]

for i, name in enumerate(names):
    print(i, name)      # 0 小明 / 1 小红 / 2 小刚
```

## 六、循环执行过程与调试方法

初学循环最有效的方法不是背，而是手工跟踪每一轮：

```python
total = 0

for number in [10, 20, 30]:
    total = total + number
    print(f"当前数字={number}，累计值={total}")

print("最终总和：", total)
```

运行过程：

| 轮次 | `number` | 执行前 `total` | 执行后 `total` |
| ---: | ---: | ---: | ---: |
| 1 | 10 | 0 | 10 |
| 2 | 20 | 10 | 30 |
| 3 | 30 | 30 | 60 |

如果结果不对，在循环内部打印“当前元素”和“累计结果”，通常很快就能发现是哪一轮出错。确认正确后再删掉调试用的 `print()`。

### 什么时候用 `for`，什么时候用 `while`

- 已经知道要遍历什么，或知道重复次数：优先用 `for`。
- 不知道循环多少次，只知道“满足条件就继续”：使用 `while`。
- `while` 循环必须确认条件最终会变成 False，否则会成为死循环。

## 七、本周产出：词频统计（逐轮拆解）

需求：给一句话，统计每个词出现几次，按次数从多到少输出。

```python
text = "python is easy and python is fun and python is powerful"

# 第 1 步：按空格拆成单词列表
words = text.split()
print(words)

# 第 2 步：准备空字典，用“单词 -> 次数”保存结果
counts = {}

# 每轮处理一个单词
for word in words:
    if word in counts:
        counts[word] += 1     # 已经有了，加 1
    else:
        counts[word] = 1      # 第一次见，记为 1

# 第 3 步：把 (单词, 次数) 按次数从大到小排序
# item[0] 是单词，item[1] 是次数；reverse=True 表示降序
sorted_items = sorted(
    counts.items(),
    key=lambda item: item[1],
    reverse=True
)

# 第 4 步：输出排好序的结果
for word, count in sorted_items:
    print(f"{word}: {count} 次")
```

输出：

```
python: 3 次
is: 3 次
easy: 1 次
and: 2 次
fun: 1 次
powerful: 1 次
```

**这个程序就是本周的核心产出。** 先照着敲通，再自己改成「统计一段中文的每个字出现几次」。

第一次遇到 `lambda` 不需要马上掌握。当前只要知道 `key=lambda item: item[1]` 的意思是“排序时看每一项的第2个值，也就是出现次数”。第3周会正式学习函数。

## 八、常见错误对照表

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `IndexError: list index out of range` | 列表没这么长 | `len()` 检查，最后一个下标是 `len-1` |
| `KeyError: 'xxx'` | 字典里没这个键 | 用 `.get("xxx")`，或先 `in` 判断 |
| `IndentationError: expected an indented block` | `if`/`for` 下面没缩进 | 加 4 个空格 |
| `IndentationError: unindent does not match` | 空格和 Tab 混用 | 全部改成空格 |
| 程序卡住不动 | `while` 死循环，忘了改条件 | 检查循环里有没有让条件变化 |
| `for i in range(1, 10)` 循环不到 10 | `range` 含头不含尾 | 改成 `range(1, 11)` |
| `TypeError: 'int' object is not iterable` | 对数字用了 `for` | 用 `range(n)` |
| 边遍历列表边删除，结果不对 | 边迭代边改长度 | 复制一份再遍历：`for x in lst[:]` |

### 常用数据结构

```python
# ============================================================
# 第 2 周：常用数据结构

# ============================================================

# ============================================================
# 第一部分：列表 List
# ============================================================

# ---- 1. 创建列表 ----
# 列表用中括号 [] 表示，可以放任意类型的数据
fruits = ["苹果", "香蕉", "橙子"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]   # 列表里可以混合不同类型

print(fruits)
print(numbers)

# ---- 2. 索引和切片（和字符串一样）----
print(fruits[0])        # 苹果
print(fruits[-1])       # 橙子
print(numbers[1:4])     # [2, 3, 4]

# ---- 3. 修改元素（列表可以改，字符串不行）----
fruits[0] = "梨"        # 把第 0 个改成梨

fruits.append("葡萄")     # 在末尾添加

fruits.insert(1, "西瓜")  # 在指定位置插入
print(fruits)

# 删
fruits.remove("香蕉")     # 删除指定元素（按值删除）
print(fruits)

last = fruits.pop()       # 弹出最后一个元素，并返回它
print(last, fruits)

# 查
print("梨" in fruits)     # 判断元素是否在列表里，返回 True/False
print(len(fruits))        # 列表长度

# ---- 5. 遍历列表 ----

for fruit in fruits:
    print(f"我喜欢吃{fruit}")

# ---- 6. 排序 ----
nums = [3, 1, 4, 1, 5, 9, 2]
nums.sort()               # 原地排序（改变原列表）
print(nums)

nums2 = [3, 1, 4, 1, 5]
sorted_nums = sorted(nums2)   # 返回新列表（不改变原列表）
print(nums2, sorted_nums)

# ---- 7. 列表推导式（高级但很有用）----
# 用一行代码生成一个新列表
squares = [x * x for x in range(1, 6)]   # 1 到 5 的平方
print(squares)   # [1, 4, 9, 16, 25]

# ============================================================
# 第二部分：元组、字典、集合
# ============================================================

# ---- 1. 元组 tuple ----
# 用圆括号 () 表示，和列表很像，但"不可修改"
point = (3, 5)          # 一个坐标点
names = ("小明", "小红", "小刚")

print(point[0])         # 3，可以访问
print(names[1])         # 小红

# point[0] = 10         # 报错！元组不能修改
# 元组适合存"固定不变"的数据，比如坐标、星期几

# ---- 2. 字典 dict ----
# 用花括号 {} 表示，存"键值对"（名字 -> 数据）
# 就像一本字典：通过"词"查到"解释"
person = {
    "name": "小明",
    "age": 18,
    "city": "北京"
}

print(person["name"])    # 通过键获取值：小明
print(person["age"])     # 18

# 添加 / 修改
person["height"] = 175   # 添加新键值对
person["age"] = 19       # 修改已有键的值
print(person)

# 删除
del person["city"]       # 删除某个键
print(person)

# 常用操作
print(person.keys())     # 所有键
print(person.values())   # 所有值
print(person.items())    # 所有键值对

# 遍历字典
for key, value in person.items():
    print(f"{key} 是 {value}")

# 安全取值：用 get，键不存在时不会报错
print(person.get("name"))        # 小明
print(person.get("不存在的键", "默认值"))   # 没有就返回默认值

# ---- 3. 集合 set ----
# 用花括号 {} 或 set() 表示，特点：不重复、无序
colors = {"红", "蓝", "绿", "红"}   # 重复的"红"会自动去掉
print(colors)        # 可能显示 {'蓝', '绿', '红'}，顺序不定

number_set = {1, 2, 3, 3, 2, 1}
print(number_set)    # {1, 2, 3}，自动去重

# 集合运算
set_a = {1, 2, 3}
set_b = {2, 3, 4}
print(set_a | set_b)    # 并集 {1, 2, 3, 4}
print(set_a & set_b)    # 交集 {2, 3}
print(set_a - set_b)    # 差集 {1}（在 set_a 里但不在 set_b 里）

# 去重的实用例子
duplicate_numbers = [1, 2, 2, 3, 3, 3]
unique_numbers = list(set(duplicate_numbers))
print(unique_numbers)
``` 

### 条件判断与循环

```python
# ============================================================
# 第 2 周：条件判断与循环
# 目标：让程序根据不同情况作出选择，并能够重复执行任务
# ============================================================

# ============================================================
# 第一部分：条件判断
# ============================================================

# ---- 1. if / elif / else ----
# if     ：如果满足条件，就执行
# elif   ：否则如果满足另一个条件，就执行（可以写多个）
# else   ：以上都不满足时执行（可省略）

score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")

# 注意：从上往下判断，命中第一个满足的条件后，后面的不再执行
# 所以上面的 85 会输出"良好"，不会继续判断 60

# ---- 2. 简单的 if ----
age = 20
if age >= 18:
    print("成年了")

# ---- 3. 嵌套条件 ----
# 条件里还可以套条件
num = 15
if num > 0:
    if num % 2 == 0:      # % 是取余，等于 0 就是偶数
        print("正偶数")
    else:
        print("正奇数")
else:
    print("非正数")

# ---- 4. 三元表达式 ----
# 一行写完的简单 if-else
n = 10
result = "偶数" if n % 2 == 0 else "奇数"
print(result)

# ---- 5. 常见错误提醒 ----
# 1) 条件后面要加冒号 :
# 2) 属于 if 块的代码要缩进
# 3) 判断相等用 ==，不是 =

# ============================================================
# 第二部分：循环
# ============================================================

# ---- 1. for 循环 ----
# 一个一个取出可迭代对象里的元素
for i in [1, 2, 3, 4, 5]:
    print(i)

# 配合 range() 生成数字序列
# range(n)     生成 0 到 n-1
# range(a, b)  生成 a 到 b-1
print("--- range 示例 ---")
for i in range(3):          # 0, 1, 2
    print(i)

for i in range(2, 6):       # 2, 3, 4, 5
    print(i)

# 遍历字符串
for char in "Python":
    print(char)

# ---- 2. while 循环 ----
# 只要条件为真，就一直重复
count = 0
while count < 3:
    print(f"第 {count} 次")
    count += 1            # 每次让 count 加 1，否则会死循环！

# ---- 3. break 和 continue ----
# break     ：立即结束整个循环
# continue  ：跳过本次，进入下一轮

print("--- break ---")
for i in range(10):
    if i == 3:
        break             # 到 3 就停止
    print(i)              # 输出 0 1 2

print("--- continue ---")
for i in range(5):
    if i == 2:
        continue          # 跳过 2
    print(i)              # 输出 0 1 3 4

# ---- 4. 循环嵌套 ----
# 打印乘法口诀表（外层循环控制行，内层循环控制列）
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end="\t")   # end 让 print 不换行
    print()               # 一行打完换行

# ---- 5. for-else ----
# 如果循环正常结束（没被 break 打断），就执行 else
for i in range(3):
    print(i)
else:
    print("循环正常结束")
``` 

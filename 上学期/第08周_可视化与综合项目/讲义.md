## 一、第一个要解决的问题：选对图

**选错图是数据分析里最常见的低级错误。** 先想清楚你要表达什么，再选图：

| 你想表达 | 用这个图 | 例子 |
| --- | --- | --- |
| 随时间**变化**的趋势 | 折线图 | 一周的每日成绩、一年的气温 |
| 不同类别**比大小** | 柱状图 | 各城市平均分、各科平均分 |
| 两个变量有没有**关系** | 散点图 | 年龄 vs 成绩、广告费 vs 销量 |
| 一批数据**怎么分布** | 直方图 | 全班分数的分布、身高的分布 |
| 占比构成 | 饼图（少用） | 各来源占比 |

> 一句话记：**趋势折线、对比柱状、关系散点、分布直方。** 拿不准时先问自己「我想让别人看出什么」。

## 二、Matplotlib 起步

### 先解决中文乱码（第一步，必做）

```python
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]   # Windows 自带的中文字体
plt.rcParams["axes.unicode_minus"] = False     # 让负号正常显示
```

不加这两行，图里的中文会变成一堆方块，负号也会变成方块。

> macOS 换成 `["Arial Unicode MS"]` 或 `["PingFang SC"]`；Linux 换成 `["Noto Sans CJK SC"]` 之类。

### 画一张图的最小骨架

```python
plt.figure(figsize=(8, 4))      # 新建画布，宽 8 英寸高 4 英寸
plt.plot(x, y)                  # 画
plt.title("标题")
plt.xlabel("x 轴名称")
plt.ylabel("y 轴名称")
plt.savefig("chart.png", dpi=150, bbox_inches="tight")   # 保存
plt.show()                      # 显示
```

> 顺序很重要：`savefig` 要写在 `show` **之前**，否则存出来是空白图。

## 三、四种基本图

### 1. 折线图：看趋势

```python
days = ["周一", "周二", "周三", "周四", "周五"]
scores = [80, 85, 78, 92, 88]

plt.figure(figsize=(8, 4))
plt.plot(days, scores, marker="o", color="steelblue", linewidth=2, label="成绩")
plt.title("本周成绩变化")
plt.xlabel("星期")
plt.ylabel("分数")
plt.grid(alpha=0.3)          # 网格线，alpha 控制透明度
plt.legend()                 # 显示图例（前面有 label 才有内容）
plt.show()
```

- `marker="o"`：每个数据点画个圆点，少数据量时更好看
- 多条线：再调一次 `plt.plot(...)`，每条的 `label` 不同

### 2. 柱状图：比大小

```python
cities = ["北京", "上海", "广州"]
avg = [84.5, 75.0, 88.0]

plt.figure(figsize=(6, 4))
bars = plt.bar(cities, avg, color=["#4C72B0", "#DD8452", "#55A868"])
plt.title("各城市平均分")
plt.ylabel("平均分")

# 柱子上标数值
for bar, v in zip(bars, avg):
    plt.text(bar.get_x() + bar.get_width() / 2, v + 0.5, f"{v:.1f}", ha="center")

plt.ylim(0, max(avg) * 1.15)     # 留出上方空间给数字
plt.show()
```

> 类别多（>6 个）或名字长时，用横向柱状图 `plt.barh(...)` 更清楚。

### 3. 散点图：看关系

```python
ages = [18, 19, 18, 20, 21]
scores = [92, 85, 77, 88, 65]

plt.figure(figsize=(6, 4))
plt.scatter(ages, scores, s=80, alpha=0.7, color="crimson")
plt.title("年龄与成绩的关系")
plt.xlabel("年龄")
plt.ylabel("成绩")
plt.show()
```

> 看图判断关系：点成一团斜向右上的云 → 正相关；散乱无规律 → 没关系。**注意：相关不等于因果。**

### 4. 直方图：看分布

```python
import numpy as np
scores = np.random.randint(50, 100, 200)

plt.figure(figsize=(6, 4))
plt.hist(scores, bins=10, color="steelblue", edgecolor="white")
plt.title("成绩分布")
plt.xlabel("分数")
plt.ylabel("人数")
plt.show()
```

- `bins` 是分多少个区间。太少看不出形状，太多变成锯齿，一般 8～20。
- 和柱状图的区别：**柱状图比不同类别的值，直方图看一组数据的分布。**

### 5. 一张画布放多张图

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 4))    # 1 行 2 列

axes[0].bar(cities, avg, color="steelblue")
axes[0].set_title("各城市平均分")

axes[1].hist(scores, bins=10, edgecolor="white")
axes[1].set_title("成绩分布")

plt.tight_layout()              # 自动调整间距，防止标题被挤掉
plt.savefig("report.png", dpi=150, bbox_inches="tight")
plt.show()
```

> 用 `axes[i]` 时，设置标题要用 `axes[i].set_title()`，不是 `plt.title()`（后者会写到最后一个子图上）。

### 6. Pandas 直接画图（更省事）

```python
df.groupby("city")["score"].mean().plot(kind="bar", figsize=(6, 4), title="各城市平均分")
plt.show()
```

`kind` 可以是 `"line"` / `"bar"` / `"barh"` / `"scatter"` / `"hist"`。**做快速探索时用这个，做正式报告时用 `plt` 精细控制。**

## 四、综合项目：完整走一遍

这是本学期的结课项目。用第 7 周的数据继续。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

# ===== 1. 读数据 =====
df = pd.read_csv("students.csv", encoding="utf-8")
print("原始形状：", df.shape)

# ===== 2. 检查与清洗 =====
print(df.info())
print("缺失情况：\n", df.isna().sum())

df["score"] = pd.to_numeric(df["score"], errors="coerce")
before = len(df)
df = df.dropna(subset=["score"])
df["city"] = df["city"].fillna("未知")
print(f"清洗：删除 {before - len(df)} 行，剩 {len(df)} 行")

# ===== 3. 分组统计 =====
by_city = df.groupby("city")["score"].agg(["count", "mean", "max"]).round(1)
by_city = by_city.sort_values("mean", ascending=False)
print(by_city)

# ===== 4. 出图 =====
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].barh(by_city.index, by_city["mean"], color="steelblue")
axes[0].set_title("各城市平均分")
axes[0].set_xlabel("平均分")
for i, v in enumerate(by_city["mean"]):
    axes[0].text(v + 0.3, i, f"{v:.1f}", va="center")

axes[1].hist(df["score"], bins=8, color="#55A868", edgecolor="white")
axes[1].set_title("成绩分布")
axes[1].set_xlabel("分数")
axes[1].set_ylabel("人数")

plt.tight_layout()
plt.savefig("report.png", dpi=150, bbox_inches="tight")
plt.show()

# ===== 5. 导出 =====
by_city.to_csv("summary.csv", encoding="utf-8-sig")
```

### 报告怎么写（这是评分重点）

```markdown
# 学生成绩分析报告

## 一、数据说明
- 来源：xxx
- 规模：原始 N 行 M 列，清洗后 N' 行
- 清洗做了：删除 score 缺失 K 行；city 缺失填「未知」J 条

## 二、核心发现
1. 广州平均分最高（88.0），比最低的上海高 13.0 分。→ 图 1
2. 分数集中在 75–95，呈左偏分布，低分段人少。→ 图 2
3. ……

## 三、结论与局限
- 结论：……
- 局限：样本只有 N 条，不足以代表全体；K 条缺失被删除，可能引入偏差
```

**四条硬性要求**：

1. **数据从哪来、多少条**，清洗前后行数必须写清楚。
2. **每个发现都要有数据或图支撑**，不能只写「感觉」。
3. **每张图配一句话**说明它证明了什么——图不是装饰。
4. **必须写局限**。这是分析者和「贴图的人」的分界线。

## 五、常见错误对照表

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 图里中文全是方块 | 没设中文字体 | 加 `plt.rcParams["font.sans-serif"] = ["SimHei"]` |
| 负号是方块 | 没关 unicode_minus | 加 `axes.unicode_minus = False` |
| 保存的图是空白 | `savefig` 写在 `show` 之后 | 把 `savefig` 挪到 `show` 前面 |
| 两张图叠在一起 | 没开新画布 | 每张图前 `plt.figure()`，或用 `subplots` |
| 子图标题只出现一次 | 用了 `plt.title()` | 改用 `axes[i].set_title()` |
| 柱子上的数字被切掉 | y 轴范围不够 | `plt.ylim(0, max*1.15)` |
| 图里啥都没有 | 数据是 NaN 或被过滤空了 | `print(df.shape)` 先确认有数据 |
| 中文类别挤在一起 | 类别太多 | 改横向柱状图，或只画前 N 项 |
| 用饼图展示 20 个类别 | 选错图 | 换柱状图 |

## 一、变量：给数据起个名字

变量就是一个**贴了标签的盒子**。`=` 的意思是「把右边的东西放进左边的盒子里」。

```python
name = "小明"      # 文字（字符串）
age = 18          # 整数
height = 175.5    # 小数
is_student = True # 真假（布尔值）
```

起名字的规矩：

| 规则 | 例子 |
| --- | --- |
| 只能用字母、数字、下划线 | `user_name` ✅ `user-name` ❌ |
| 不能以数字开头 | `name2` ✅ `2name` ❌ |
| 区分大小写 | `Age` 和 `age` 是两个东西 |
| 不能和关键字重名 | `class`、`if`、`for`、`print` 都不能当变量名 |
| 用英文小写 + 下划线 | `total_score` ✅ `TotalScore` 也可以但不推荐 |

> 中文当变量名 Python 允许，但**不要这么干**。以后看别人代码、搜报错时会给自己找麻烦。

## 二、数据类型：`type()` 一查就知道

```python
print(type(18))       # <class 'int'>     整数
print(type(175.5))    # <class 'float'>   小数
print(type("小明"))    # <class 'str'>     字符串
print(type(True))     # <class 'bool'>    布尔值
```

类型可以转换，这是后面最常用的操作：

```python
print(int("18") + 1)     # 19   字符串 "18" 变成整数 18
print(float("3.14"))     # 3.14
print(str(18) + "岁")     # 18岁  数字变成字符串才能拼
print(int(3.9))          # 3     小数转整数是直接砍掉小数部分，不是四舍五入
```

## 三、输出与输入

```python
print("你好")                 # 你好
print("你好", "世界")          # 你好 世界（逗号之间自动加空格）
print("a", "b", sep="-")      # a-b（自定义分隔符）
print("第一行\n第二行")        # \n 是换行
```

输入用的是 `input()`，**要注意一个坑**：

```python
name = input("请输入你的名字：")   # 拿到的一定是字符串
age = input("请输入你的年龄：")    # ⚠️ 这里拿到的也是字符串！

print(type(age))                  # <class 'str'>
print(age + 1)                    # ❌ 报错：TypeError
```

正确写法是先转换：

```python
age = int(input("请输入你的年龄："))
print(age + 1)                    # ✅
```

## 四、运算符

### 1. 算术运算符

```python
a, b = 10, 3

print(a + b)    # 13    加
print(a - b)    # 7     减
print(a * b)    # 30    乘
print(a / b)    # 3.3333333333333335   除，结果一定是小数
print(a // b)   # 3     整除，砍掉小数部分
print(a % b)    # 1     取余，求余数
print(a ** b)   # 1000  幂，10 的 3 次方
```

除法 `/` 永远返回小数，这点和整除 `//` 要分清楚：

```python
print(10 / 2)   # 5.0   不是 5
print(10 // 2)  # 5     整数
```

### 2. 比较运算符

比较的结果永远是 `True` 或 `False`：

```python
x, y = 5, 10

print(x == y)   # False   等于（两个等号！）
print(x != y)   # True    不等于
print(x < y)    # True    小于
print(x >= y)   # False   大于等于
```

> **`=` 是赋值，`==` 才是比较。** 这是零基础第一大错误来源。
> `x = 5` 是「把 5 给 x」，`x == 5` 是「x 等于 5 吗」。

### 3. 逻辑运算符

```python
p, q = True, False

print(p and q)  # False   且：两边都为真才为真
print(p or q)   # True    或：有一边为真就为真
print(not p)    # False   非：取反
```

常见用法是判断区间：

```python
age = 20
print(age > 10 and age < 30)   # True
```

### 4. 赋值运算符（简写）

```python
n = 5
n += 3      # 等价于 n = n + 3，现在 n 是 8
n -= 2      # n 是 6
n *= 4      # n 是 24
print(n)
```

## 五、字符串

### 1. 三种写法

```python
s1 = "双引号"
s2 = '单引号'
s3 = """三引号
可以写很多行
也可以当注释用"""
print(s3)
```

### 2. 索引与切片

字符串里每个字符都有编号，**从 0 开始**：

```python
text = "Hello Python"

print(text[0])     # H    第一个
print(text[1])     # e    第二个
print(text[-1])    # n    倒数第一个（负数从右往左）
print(text[0:5])   # Hello   取 0 到 4，不含 5
print(text[6:])    # Python  从 6 取到末尾
print(text[:5])    # Hello   从头取到 4
print(len(text))   # 12      长度
```

切片的口诀：**`[开始:结束]` 含开始、不含结束**。

### 3. 五个必会方法

方法就是「挂在数据上的函数」，用 `点.方法名()` 调用：

```python
word = "  Hello World  "

print(word.upper())                        # "  HELLO WORLD  "   全大写
print(word.lower())                        # "  hello world  "   全小写
print(word.strip())                        # "Hello World"       去掉两端空格
print(word.replace("World", "Python"))     # "  Hello Python  "  替换
print("a b c".split())                     # ['a', 'b', 'c']     按空格拆成列表
print("hello".find("e"))                   # 1                   找位置，找不到返回 -1
```

> `strip()` 在清洗数据时天天用，因为从文件里读出来的数据经常带多余空格和换行。

### 4. f-string：最舒服的拼接方式

```python
name = "小明"
age = 18

print("我叫" + name + "，今年" + str(age) + "岁")   # 老写法，还要 str()
print(f"我叫{name}，今年{age}岁")                  # ✅ 推荐
print(f"明年我就{age + 1}岁了")                    # 大括号里还能算
print(f"身高{175.5:.1f}cm")                        # 保留 1 位小数
```

## 七、完整示例：个人信息卡

```python
# 输入个人信息，输出一张信息卡
name = input("请输入姓名：")
age = int(input("请输入年龄："))
city = input("请输入城市：")

next_year_age = age + 1

print("=" * 30)
print(f"姓名：{name}")
print(f"年龄：{age} 岁（明年 {next_year_age} 岁）")
print(f"城市：{city}")
print("=" * 30)
```

运行效果：

```
请输入姓名：小明
请输入年龄：18
请输入城市：北京
==============================
姓名：小明
年龄：18 岁（明年 19 岁）
城市：北京
==============================
```

## 八、常见错误对照表

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `TypeError: can only concatenate str (not "int") to str` | 字符串和数字直接相加 | 用 `str()` 转换，或改用 f-string |
| `TypeError: unsupported operand type(s) for +: 'int' and 'str'` | `input()` 拿到的是字符串 | 用 `int(input(...))` |
| `SyntaxError: invalid syntax` 指向中文引号 | 用了中文的 `“”` | 换成英文 `""` 或 `''` |
| `if x = 5:` 报错 | 把 `==` 写成 `=` | 改成 `x == 5` |
| `IndexError: string index out of range` | 索引超出长度 | 检查 `len()`，最小是 0，最大是 `len-1` |
| `NameError: name 'nmae' is not defined` | 变量名拼错 | 检查拼写，大小写也要一致 |
| `IndentationError` | 缩进乱了（空格和 Tab 混用） | 统一用 4 个空格 |

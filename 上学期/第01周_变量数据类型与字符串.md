## 一、变量：给数据起个名字

变量就是一个**贴了标签的盒子**。`=` 的意思是「把右边的东西放进左边的盒子里」。

```python
name = "小明"      # 文字（字符串）
age = 18          # 整数
height = 175.5    # 小数
is_student = True # 真假（布尔值）
```

起名字的规矩：

| 规则 | 例子 |
| --- | --- |
| 只能用字母、数字、下划线 | `user_name` ✅ `user-name` ❌ |
| 不能以数字开头 | `name2` ✅ `2name` ❌ |
| 区分大小写 | `Age` 和 `age` 是两个东西 |
| 不能和关键字重名 | `class`、`if`、`for`、`print` 都不能当变量名 |
| 用英文小写 + 下划线 | `total_score` ✅ `TotalScore` 也可以但不推荐 |

> 中文当变量名 Python 允许，但**不要这么干**。以后看别人代码、搜报错时会给自己找麻烦。

## 二、数据类型：`type()` 一查就知道

```python
print(type(18))       # <class 'int'>     整数
print(type(175.5))    # <class 'float'>   小数
print(type("小明"))    # <class 'str'>     字符串
print(type(True))     # <class 'bool'>    布尔值
```

类型可以转换，这是后面最常用的操作：

```python
print(int("18") + 1)     # 19   字符串 "18" 变成整数 18
print(float("3.14"))     # 3.14
print(str(18) + "岁")     # 18岁  数字变成字符串才能拼
print(int(3.9))          # 3     小数转整数是直接砍掉小数部分，不是四舍五入
```

## 三、输出与输入

```python
print("你好")                 # 你好
print("你好", "世界")          # 你好 世界（逗号之间自动加空格）
print("a", "b", sep="-")      # a-b（自定义分隔符）
print("第一行\n第二行")        # \n 是换行
```

输入用的是 `input()`，**要注意一个坑**：

```python
name = input("请输入你的名字：")   # 拿到的一定是字符串
age = input("请输入你的年龄：")    # ⚠️ 这里拿到的也是字符串！

print(type(age))                  # <class 'str'>
print(age + 1)                    # ❌ 报错：TypeError
```

正确写法是先转换：

```python
age = int(input("请输入你的年龄："))
print(age + 1)                    # ✅
```

## 四、运算符

### 1. 算术运算符

```python
a, b = 10, 3

print(a + b)    # 13    加
print(a - b)    # 7     减
print(a * b)    # 30    乘
print(a / b)    # 3.3333333333333335   除，结果一定是小数
print(a // b)   # 3     整除，砍掉小数部分
print(a % b)    # 1     取余，求余数
print(a ** b)   # 1000  幂，10 的 3 次方
```

除法 `/` 永远返回小数，这点和整除 `//` 要分清楚：

```python
print(10 / 2)   # 5.0   不是 5
print(10 // 2)  # 5     整数
```

### 2. 比较运算符

比较的结果永远是 `True` 或 `False`：

```python
x, y = 5, 10

print(x == y)   # False   等于（两个等号！）
print(x != y)   # True    不等于
print(x < y)    # True    小于
print(x >= y)   # False   大于等于
```

> **`=` 是赋值，`==` 才是比较。** 这是零基础第一大错误来源。
> `x = 5` 是「把 5 给 x」，`x == 5` 是「x 等于 5 吗」。

### 3. 逻辑运算符

```python
p, q = True, False

print(p and q)  # False   且：两边都为真才为真
print(p or q)   # True    或：有一边为真就为真
print(not p)    # False   非：取反
```

常见用法是判断区间：

```python
age = 20
print(age > 10 and age < 30)   # True
```

### 4. 赋值运算符（简写）

```python
n = 5
n += 3      # 等价于 n = n + 3，现在 n 是 8
n -= 2      # n 是 6
n *= 4      # n 是 24
print(n)
```

## 五、字符串

### 1. 三种写法

```python
s1 = "双引号"
s2 = '单引号'
s3 = """三引号
可以写很多行
也可以当注释用"""
print(s3)
```

### 2. 索引与切片

字符串里每个字符都有编号，**从 0 开始**：

```python
text = "Hello Python"

print(text[0])     # H    第一个
print(text[1])     # e    第二个
print(text[-1])    # n    倒数第一个（负数从右往左）
print(text[0:5])   # Hello   取 0 到 4，不含 5
print(text[6:])    # Python  从 6 取到末尾
print(text[:5])    # Hello   从头取到 4
print(len(text))   # 12      长度
```

切片的口诀：**`[开始:结束]` 含开始、不含结束**。

### 3. 六个常用方法

方法就是「挂在数据上的函数」，用 `点.方法名()` 调用：

```python
# 原始字符串左右各有两个空格，方便观察不同方法的效果
word = "  Hello World  "

print(word.upper())                     # 返回全大写的新字符串："  HELLO WORLD  "
print(word.lower())                     # 返回全小写的新字符串："  hello world  "
print(word.strip())                     # 去掉两端空格："Hello World"
print(word.replace("World", "Python"))  # 把指定内容替换掉："  Hello Python  "
print("a b c".split())                  # 按空格拆分，得到列表 ['a', 'b', 'c']
print("hello".find("e"))                # 返回 e 第一次出现的位置 1；找不到返回 -1
```

这些方法都**不会修改原字符串**，而是返回一个新字符串。运行 `print(word)`，你会发现 `word` 仍然是原来的内容。如果希望保存处理结果，要重新赋值：

```python
# strip() 产生新字符串，再把新字符串交给 clean_word
clean_word = word.strip()

print(word)        # 原字符串仍有空格
print(clean_word)  # Hello World
```

> `strip()` 在清洗数据时天天用，因为从文件里读出来的数据经常带多余空格和换行。

### 4. f-string：最舒服的拼接方式

```python
name = "小明"
age = 18

print("我叫" + name + "，今年" + str(age) + "岁")   # 老写法，还要 str()
print(f"我叫{name}，今年{age}岁")                  # ✅ 推荐
print(f"明年我就{age + 1}岁了")                    # 大括号里还能算
print(f"身高{175.5:.1f}cm")                        # 保留 1 位小数
```

## 六、注释

```python
# 单行注释以 # 开头，只给人看，Python 不会执行
# 适合解释下一行代码为什么这样写
price = 9.9  # 行尾也能写注释，但不要写得太长

"""
三引号真正创建的是“多行字符串”，严格来说不是注释。
放在模块、函数或类的第一行时，它叫文档字符串（docstring）。
"""
```

注释应该解释“为什么”，不要重复“代码表面做了什么”。例如 `age = age + 1  # 年龄加1` 信息量很低；写成 `# 计算明年的年龄，原 age 保持不变` 更有帮助。

## 七、代码是怎样一步步执行的

Python 默认从文件第一行开始，按照从上到下的顺序执行。遇到 `input()` 时暂停等待输入；遇到 `print()` 时把结果显示到终端。

```python
# 第 1 步：先把 10 保存到变量 number
number = 10

# 第 2 步：读取 number 的当前值 10，计算 10 + 5，再把 15 存回 number
number = number + 5

# 第 3 步：读取更新后的 number，所以输出 15
print(number)
```

可以用“手工跟踪表”理解变量变化：

| 执行到哪一行 | `number` 的值 | 屏幕输出 |
| --- | ---: | --- |
| `number = 10` | 10 | 无 |
| `number = number + 5` | 15 | 无 |
| `print(number)` | 15 | 15 |

### 变量、值和类型不是一回事

看 `age = 18` 时，把它拆成三部分：

- `age`：变量名，负责让我们以后找到这个值。
- `18`：实际保存的数据。
- `int`：数据类型，决定这个值可以参加哪些操作。

```python
age = 18
print(age)        # 输出值：18
print(type(age))  # 输出类型：<class 'int'>

# 同一个变量可以重新指向另一种类型的值，但初学阶段不建议这样写
age = "十八"
print(age)        # 输出值：十八
print(type(age))  # 输出类型：<class 'str'>
```

Python 允许变量更换类型，但实际项目中，一个变量最好始终表达同一种含义，否则代码会很难读。

### 转换失败时怎么看报错

下面的代码会故意报错：

```python
age_text = "十八"
age = int(age_text)  # ValueError：中文“十八”不是由数字字符组成的字符串
```

报错信息通常从最后一行开始看：

```text
ValueError: invalid literal for int() with base 10: '十八'
```

排查顺序：

1. 看异常名称：这里是 `ValueError`，说明值的内容不适合转换。
2. 看最后显示的数据：这里是 `'十八'`。
3. 回到报错行，检查 `int()` 收到了什么。
4. 不要直接删除报错代码，要先确认业务上应该拒绝输入，还是提示用户重输。异常处理会在第4周系统学习。

### 切片的完整形式

切片完整写法是 `字符串[开始:结束:步长]`：

```python
text = "Python"

print(text[1:5])    # ytho：从位置 1 到位置 4
print(text[::2])    # Pto：从头到尾，每隔 2 个取一个
print(text[::-1])   # nohtyP：步长为 -1，倒序取字符
```

索引超出范围会报错，但切片超过范围通常不会：

```python
text = "Python"

# print(text[100])  # IndexError：不存在第 100 号字符
print(text[0:100])  # Python：切片会在字符串末尾自动停止
```

## 八、完整示例：个人信息卡（逐行解释）

```python
# ---------- 输入阶段 ----------
# input() 返回 str，所以姓名和城市可以直接保存
name = input("请输入姓名：").strip()  # 顺便去掉用户误输入的首尾空格
city = input("请输入城市：").strip()

# 年龄后面要参与加法，必须先用 int() 转成整数
age_text = input("请输入年龄：")
age = int(age_text)

# ---------- 处理阶段 ----------
# 使用新变量保存计算结果，不覆盖原来的 age，含义更清楚
next_year_age = age + 1

# ---------- 输出阶段 ----------
# 字符串乘整数会重复内容；"=" * 30 会得到 30 个等号
separator = "=" * 30

print(separator)
print(f"姓名：{name}")
print(f"年龄：{age} 岁（明年 {next_year_age} 岁）")
print(f"城市：{city}")
print(separator)
```

这段程序采用了以后反复使用的三段式结构：

1. **输入**：从用户或文件获得原始数据。
2. **处理**：转换类型、计算、清洗数据。
3. **输出**：把结果打印、保存或画图。

如果程序出错，可以先判断错误发生在哪一个阶段，而不是从头盲目检查。

运行效果：

```
请输入姓名：小明
请输入年龄：18
请输入城市：北京
==============================
姓名：小明
年龄：18 岁（明年 19 岁）
城市：北京
==============================
```

## 九、常见错误对照表

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `TypeError: can only concatenate str (not "int") to str` | 字符串和数字直接相加 | 用 `str()` 转换，或改用 f-string |
| `TypeError: unsupported operand type(s) for +: 'int' and 'str'` | `input()` 拿到的是字符串 | 用 `int(input(...))` |
| `SyntaxError: invalid syntax` 指向中文引号 | 用了中文的 `“”` | 换成英文 `""` 或 `''` |
| `if x = 5:` 报错 | 把 `==` 写成 `=` | 改成 `x == 5` |
| `IndexError: string index out of range` | 索引超出长度 | 检查 `len()`，最小是 0，最大是 `len-1` |
| `NameError: name 'nmae' is not defined` | 变量名拼错 | 检查拼写，大小写也要一致 |
| `IndentationError` | 缩进乱了（空格和 Tab 混用） | 统一用 4 个空格 |

# 第一部分：运算符
# ============================================================

# ---- 1. 算术运算符 ----
a = 10
b = 3

print(a + b)     # 13   加法
print(a - b)     # 7    减法
print(a * b)     # 30   乘法
print(a / b)     # 3.333...  除法（结果一定是小数）
print(a // b)    # 3    整除（只取整数部分）
print(a % b)     # 1    取余（求余数）
print(a ** b)    # 1000 幂运算（10 的 3 次方）

# ---- 2. 比较运算符（结果是 True 或 False）----
x = 5
y = 10

print(x == y)    # False  等于（注意是两个等号！）
print(x != y)    # True   不等于
print(x < y)     # True   小于
print(x > y)     # False  大于
print(x <= y)    # True   小于等于
print(x >= y)    # False  大于等于

# 注意：一个等号是赋值，两个等号才是比较
# x = 5  是"把 5 给 x"
# x == 5 是"x 等于 5 吗？"

# ---- 3. 逻辑运算符 ----
p = True
q = False

print(p and q)   # False  且：两边都为真才为真
print(p or q)    # True   或：只要一边为真就为真
print(not p)     # False  非：取反

# 常见用法：判断一个数是否在某个范围内
age = 20
print(age > 10 and age < 30)   # True，10 和 30 之间

# ---- 4. 赋值运算符 ----
n = 5
n += 3          # 相当于 n = n + 3，n 现在是 8
print(n)

n -= 2          # n = n - 2
print(n)

n *= 4          # n = n * 4
print(n)

# ============================================================
# 第二部分：字符串
# ============================================================

# ---- 1. 创建字符串 ----
s1 = "双引号"
s2 = '单引号'
s3 = """三引号
可以写多行文字"""
print(s1, s2)

# ---- 2. 转义字符 ----
# 反斜杠 \ 用来表示特殊字符
print("第一行\n第二行")   # \n 换行
print("用\t制表符分隔")    # \t 制表符（相当于 Tab 键）
print("他说：\"你好\"")    # \" 表示真正的双引号

# ---- 3. 索引和切片 ----
# 字符串里的每个字符都有位置编号（从 0 开始）
text = "Hello Python"

print(text[0])        # H    第一个字符
print(text[1])        # e    第二个字符
print(text[-1])       # n    倒数第一个（负数从右往左数）

print(text[0:5])      # Hello  取第 0 到第 4 个字符（不含第 5 个）
print(text[6:])       # Python 从第 6 个取到末尾
print(text[:5])       # Hello  从头取到第 4 个

# ---- 4. 常用方法 ----
# 方法就是"挂在数据上的函数"，用 点.方法名() 调用
word = "  Hello World  "

print(len(word))          # 长度（字符个数）
print(word.upper())       # 全转大写
print(word.lower())       # 全转小写
print(word.strip())       # 去掉两端的空格
print(word.replace("World", "Python"))   # 把 World 替换成 Python
print(word.split())       # 按空格拆成列表 ['Hello', 'World']
print("hello".find("e"))  # 找字符 e 的位置，找不到返回 -1

# ---- 5. 字符串拼接与 f-string ----
first = "张"
last = "三"
print(first + last)       # 用 + 拼接

# f-string：最方便的格式化方式，在 f 后面的大括号里放变量
name = "小明"
age = 18
print(f"我叫{name}，今年{age}岁")   # 直接嵌入变量
print(f"明年我就{age + 1}岁了")    # 大括号里还可以写计算

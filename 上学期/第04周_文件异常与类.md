## 一、读文件

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```

拆开看这行代码：

| 部分 | 意思 |
| --- | --- |
| `open(...)` | 打开文件 |
| `"data.txt"` | 文件路径（相对当前工作目录） |
| `"r"` | 模式：读（read） |
| `encoding="utf-8"` | 编码，**处理中文必须写** |
| `as f` | 给这个文件起名叫 f |
| `with` | 离开这段代码块时自动关闭文件 |

> 为什么要用 `with`？因为不用它就得手动 `f.close()`，忘了就会锁文件、丢数据。

### 三种读法

```python
with open("data.txt", "r", encoding="utf-8") as f:
    text = f.read()          # 一次性读全部，返回一个大字符串

with open("data.txt", "r", encoding="utf-8") as f:
    line = f.readline()      # 读一行

with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()    # 读成列表，每个元素是一行（带 \n）
```

### 最常用：一行一行处理

```python
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        line = line.strip()      # ⚠️ 去掉行尾的换行符
        if not line:             # 跳过空行
            continue
        print(line)
```

> `strip()` 是读文件时的高频操作，因为每行末尾都带 `\n`。

## 二、写文件

```python
# "w" 模式：覆盖写入，文件不存在会新建，存在就清空
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

# "a" 模式：追加，不会清空原有内容
with open("output.txt", "a", encoding="utf-8") as f:
    f.write("第三行\n")
```

| 模式 | 作用 | 文件已存在时 |
| --- | --- | --- |
| `"r"` | 读 | 不存在会报错 |
| `"w"` | 写 | **清空重写** |
| `"a"` | 追加 | 在末尾接着写 |

## 三、处理 CSV 文件

CSV 就是「逗号分隔的文本」，Excel 能直接打开。

假设有个 `scores.csv`：

```
name,subject,score
小明,数学,90
小红,数学,85
小刚,数学,77
```

### 方法一：当普通文本处理

```python
with open("scores.csv", "r", encoding="utf-8") as f:
    for i, line in enumerate(f):
        line = line.strip()
        if i == 0:              # 第一行是表头，跳过
            continue
        name, subject, score = line.split(",")
        print(f"{name} 的{subject}成绩是 {score}")
```

### 方法二：用 `csv` 模块（更稳）

```python
import csv

with open("scores.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)      # 用表头当键，每行变字典
    for row in reader:
        print(row["name"], row["score"])
```

> 用 `split(",")` 在数据里本身有逗号时会出错，正式项目用 `csv` 模块。之后 Pandas 的 `read_csv` 会更省事。

## 四、异常处理

程序遇到错误会抛异常，不处理就直接崩：

```python
age = int(input("年龄："))     # 用户输入 "abc" → ValueError，程序直接退出
```

用 `try / except` 兜住：

```python
try:
    age = int(input("年龄："))
    print("明年你", age + 1, "岁")
except ValueError:
    print("请输入数字！")
```

### 完整结构

```python
try:
    num = int(input("请输入除数："))
    result = 100 / num
except ValueError:
    print("这好像不是数字")
except ZeroDivisionError:
    print("除数不能是 0")
except Exception as e:
    print("出了别的错：", e)
else:
    print("一切正常，结果是", result)      # 没出错才执行
finally:
    print("不管怎样都会执行")             # 收尾，比如关文件
```

### 常见异常类型

| 异常 | 什么时候出现 |
| --- | --- |
| `ValueError` | 类型对但值不对，如 `int("abc")` |
| `TypeError` | 类型不对，如 `"a" + 1` |
| `IndexError` | 列表 / 字符串下标越界 |
| `KeyError` | 字典没有这个键 |
| `FileNotFoundError` | 文件不存在 |
| `ZeroDivisionError` | 除以 0 |
| `AttributeError` | 对象没有这个属性 / 方法 |

> 抓异常要**抓具体的类型**（`except ValueError`），别一上来就 `except Exception` 把什么都盖住——那样真正的 bug 会被藏起来，以后更难查。

## 五、类与对象（能读懂、能改就够）

先记住一句话：**类是一张图纸，对象是按图纸造出来的东西。**

```python
class Student:
    def __init__(self, name, score):
        self.name = name        # 属性
        self.score = score

    def is_pass(self):          # 方法
        return self.score >= 60

    def introduce(self):
        print(f"我是{self.name}，成绩{self.score}")


# 按图纸造两个对象
s1 = Student("小明", 92)
s2 = Student("小红", 55)

s1.introduce()              # 我是小明，成绩92
print(s1.is_pass())        # True
print(s2.is_pass())        # False
```

三件事必须理解：

1. **`class Student:`** —— 定义类，类名首字母大写。
2. **`__init__`** —— 特殊方法，**创建对象时自动执行**，用来设置初始属性。前后各两个下划线。
3. **`self`** —— 指「当前这个对象自己」。方法里访问自己的属性必须写 `self.xxx`，参数表里第一个位置永远是 `self`（调用时不传它）。

### 直接改属性

```python
s1.score = 95          # 改属性
print(s1.score)        # 95
print(s1.name)         # 小明
```

> 本周**只需要**：能看懂 `class` 长什么样、能造对象、能调方法、能改属性。继承、魔术方法、`@property` 这些**不讲**，以后需要再说。

### 为什么要有类

```python
# 用字典也能存一个学生
student = {"name": "小明", "score": 92}
# 但「判断是否及格」这个逻辑没地方放，只能到处复制
```

类的价值在于：**把数据和处理这些数据的方法绑在一起**。下周 NumPy、后面 PyTorch 里的模型，全都是类。

## 六、本周产出：读 CSV 统计行数

```python
import csv

def count_rows(filename):
    """读 CSV，返回数据行数（不含表头）"""
    count = 0
    with open(filename, "r", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        for row in reader:
            count += 1
    return count


try:
    n = count_rows("scores.csv")
    print(f"共 {n} 条数据")
except FileNotFoundError:
    print("找不到 scores.csv，请检查文件是否在当前目录")
```

注意这里把上周学的**函数**和这周学的**文件 + 异常**合在了一起，这就是学习曲线往上走的样子。

## 七、常见错误对照表

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `FileNotFoundError` | 路径不对 / 不在当前目录 | 用绝对路径，或先 `print(os.getcwd())` 看在哪 |
| `UnicodeDecodeError` | 没写 `encoding="utf-8"` 或文件是 GBK | 加上 `encoding="utf-8"`；GBK 文件用 `encoding="gbk"` |
| 读完文件后内容是空的 | 用了 `"w"` 打开，把内容清空了 | 读用 `"r"`，写才用 `"w"` |
| 每行末尾多一个空行 | 读出来的行带 `\n`，`print` 又加了一个 | 用 `line.strip()` |
| `NameError: name 'self' is not defined` | 方法里少写了 `self` | `def f(self, ...)` |
| `TypeError: introduce() takes 1 positional argument but 2 were given` | 定义方法时忘了写 `self` | 参数表第一个写 `self` |
| 程序崩了但不知道错在哪 | 没有异常处理 | 看报错最后一行的异常类型和行号 |
| `except` 写了但没兜住 | 异常类型对不上 | 看清报错里的异常名，写对类型 |

### 类与面向对象

```python
# ============================================================
# 第 4 周：面向对象（类）
# 目标：用"类"来组织代码，这是基础阶段的终点
# ============================================================

# ---- 1. 什么是类和对象 ----
# 类 = 模板（设计图）
# 对象 = 根据模板造出来的具体东西（实例）
# 比如："狗"是一个类，"你家那只叫旺财的狗"是一个对象

# ---- 2. 定义一个类 ----
class Dog:
    # __init__ 是构造方法，创建对象时自动调用
    # self 代表"当前这个对象"（必须有，但不传它）
    def __init__(self, name, age):
        self.name = name      # 给对象设置"属性"
        self.age = age

    # 类里的函数叫"方法"，第一个参数必须是 self
    def bark(self):
        print(f"{self.name} 在叫：汪汪！")

    def info(self):
        print(f"{self.name} 今年 {self.age} 岁")

# ---- 3. 创建对象（实例化）----
dog1 = Dog("旺财", 3)    # 自动调用 __init__
dog2 = Dog("小白", 5)

print(dog1.name)         # 访问属性：旺财
dog1.bark()              # 调用方法
dog1.info()

# ---- 4. 封装（私有属性）----
# 名字前加两个下划线 __，表示"私有"，外部不能直接访问
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.__balance = balance      # 私有属性

    def deposit(self, amount):        # 存钱
        self.__balance += amount

    def get_balance(self):            # 通过方法安全地查看余额
        return self.__balance

account = BankAccount("小明", 100)
account.deposit(50)
print(account.get_balance())   # 150
# print(account.__balance)     # 会报错，不能直接访问私有属性

# ---- 5. 继承 ----
# 子类继承父类，自动拥有父类的属性和方法
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(f"{self.name} 在吃东西")

class Cat(Animal):          # Cat 继承 Animal
    def meow(self):
        print(f"{self.name} 在叫：喵喵")

cat = Cat("咪咪")
cat.eat()                   # 继承来的方法
cat.meow()                  # 自己的方法

# ---- 6. 方法重写 ----
# 子类可以重新定义父类已有的方法
class Bird(Animal):
    def eat(self):          # 重写 eat 方法
        print(f"{self.name} 在啄米吃")

bird = Bird("小黄")
bird.eat()                  # 用的是重写后的版本

# ---- 7. 魔法方法 ----
# 前后都有双下划线的特殊方法，Python 会自动调用它们
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __str__(self):       # print(对象) 时自动调用
        return f"学生：{self.name}，成绩：{self.score}"

    def __repr__(self):      # 在列表等容器里显示时自动调用
        return self.__str__()

s = Student("小明", 90)
print(s)                     # 学生：小明，成绩：90

# ---- 8. 综合小练习 ----
# 做一个简单的"学生管理"
class StudentManager:
    def __init__(self):
        self.students = []      # 用列表存所有学生

    def add(self, name, score):
        self.students.append(Student(name, score))

    def show_all(self):
        for s in self.students:
            print(s)

manager = StudentManager()
manager.add("小明", 90)
manager.add("小红", 85)
manager.add("小刚", 92)
manager.show_all()
``` 

### 文件操作与异常

```python
# ============================================================
# 第 4 周：文件操作与异常处理
# 目标：读写文件，以及让程序出错时不崩溃
# ============================================================

# ---- 1. 写文件 ----
# open() 打开文件，'w' 表示写入（会覆盖原内容）
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

# with 语句的好处：用完自动关闭文件，不用手动 close()

# 'a' 表示追加（不覆盖，接着写）
with open("test.txt", "a", encoding="utf-8") as f:
    f.write("追加的一行\n")

# ---- 2. 读文件 ----
# 'r' 表示读取
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()        # 一次性读全部
    print(content)

with open("test.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()     # 读成列表，每行是一个元素
    print(lines)

# 逐行读（最常用，省内存）
with open("test.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())   # strip 去掉每行末尾的换行符

# 打开模式速查：
# 'r' 读  'w' 写(覆盖)  'a' 追加  'b' 二进制  '+' 读写

# ---- 3. 异常处理 ----
# 程序出错时会"抛异常"，如果不处理，程序就崩溃了
# try/except 可以"接住"错误，让程序继续跑

try:
    num = int("abc")    # 这行会出错："abc" 不能转成整数
except ValueError:
    print("转换失败：不是数字")

# 捕获多种异常
try:
    result = 10 / 0     # 除零错误
except ZeroDivisionError:
    print("不能除以零！")
except Exception as e:  # 捕获所有其他异常，e 是错误信息
    print(f"出错了：{e}")

# finally：无论是否出错都会执行
try:
    f = open("不存在.txt", "r")
except FileNotFoundError:
    print("文件不存在")
finally:
    print("这行一定会执行")

# ---- 4. 常见异常类型 ----
# ValueError       值错误（类型对但值不对）
# TypeError        类型错误（类型就不对）
# ZeroDivisionError 除零错误
# FileNotFoundError 文件不存在
# IndexError       索引超出范围
# KeyError         字典里没有这个键
```

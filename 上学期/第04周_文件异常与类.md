## 一、读文件

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```

拆开看这行代码：

| 部分 | 意思 |
| --- | --- |
| `open(...)` | 打开文件 |
| `"data.txt"` | 文件路径（相对当前工作目录） |
| `"r"` | 模式：读（read） |
| `encoding="utf-8"` | 按 UTF-8 规则把字节解释成文字；文本文件建议明确写出 |
| `as f` | 给这个文件起名叫 f |
| `with` | 离开这段代码块时自动关闭文件 |

> 为什么要用 `with`？因为不用它就得手动 `f.close()`；一旦中途报错，关闭操作更容易被漏掉。`with` 无论正常结束还是发生异常，都会负责关闭文件。

### 相对路径到底从哪里开始

`"data.txt"` 不是“和代码文件在一起”的绝对保证，它相对于**当前工作目录**。先运行下面的代码确认：

```python
from pathlib import Path

# cwd() 返回程序当前工作目录
current_dir = Path.cwd()
print("当前工作目录：", current_dir)

# resolve() 把相对路径转换成完整的绝对路径，方便排查
data_path = Path("data.txt")
print("准备读取：", data_path.resolve())
print("文件存在吗：", data_path.exists())
```

看到 `FileNotFoundError` 时，先看 `resolve()` 输出的位置，不要急着反复修改文件名。

### 三种读法

```python
with open("data.txt", "r", encoding="utf-8") as f:
    text = f.read()          # 一次性读完，返回一个大字符串；适合小文件

with open("data.txt", "r", encoding="utf-8") as f:
    line = f.readline()      # 只读一行；再次调用会继续读下一行

with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()    # 全部读成列表；每个元素是一行（通常带 \n）
```

三种方法都会移动文件内部的“读取位置”。同一个文件对象调用一次 `read()` 后，位置已经到了末尾，再调用会得到空字符串：

```python
with open("data.txt", "r", encoding="utf-8") as file:
    first = file.read()   # 从开头读到末尾
    second = file.read()  # 已经在末尾，所以得到 ""

print("第一次长度：", len(first))
print("第二次长度：", len(second))
```

### 最常用：一行一行处理

```python
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        line = line.strip()      # ⚠️ 去掉行尾的换行符
        if not line:             # 跳过空行
            continue
        print(line)
```

> `strip()` 是读文件时的高频操作，因为每行末尾都带 `\n`。

## 二、写文件

```python
# "w" 模式：覆盖写入，文件不存在会新建，存在就清空
with open("output.txt", "w", encoding="utf-8") as f:
    chars1 = f.write("第一行\n")  # write() 返回写入的字符数
    chars2 = f.write("第二行\n")

print("写入字符数：", chars1 + chars2)

# "a" 模式：追加，不会清空原有内容
with open("output.txt", "a", encoding="utf-8") as f:
    f.write("第三行\n")
```

运行前要确认是否真的允许覆盖旧文件。重要文件更安全的做法是先写入新文件，检查无误后再替换。

| 模式 | 作用 | 文件已存在时 |
| --- | --- | --- |
| `"r"` | 读 | 不存在会报错 |
| `"w"` | 写 | **清空重写** |
| `"a"` | 追加 | 在末尾接着写 |

## 三、处理 CSV 文件

CSV 就是「逗号分隔的文本」，Excel 能直接打开。

假设有个 `scores.csv`：

```
name,subject,score
小明,数学,90
小红,数学,85
小刚,数学,77
```

### 方法一：当普通文本处理

```python
with open("scores.csv", "r", encoding="utf-8") as f:
    for i, line in enumerate(f):
        line = line.strip()
        if i == 0:              # 第一行是表头，跳过
            continue
        name, subject, score = line.split(",")
        print(f"{name} 的{subject}成绩是 {score}")
```

### 方法二：用 `csv` 模块（更稳）

```python
import csv

with open("scores.csv", "r", encoding="utf-8", newline="") as f:
    # DictReader 读取第一行表头，把后续每行转换成字典
    reader = csv.DictReader(f)
    for row in reader:
        # CSV 读出的字段默认都是字符串，参与计算前要转换
        score = int(row["score"])
        print(row["name"], row["score"])
```

> 用 `split(",")` 在数据里本身有逗号时会出错，正式项目用 `csv` 模块。处理 CSV 时建议加 `newline=""`，让 `csv` 模块统一处理换行。之后 Pandas 的 `read_csv` 会更省事。

## 四、异常处理

程序遇到错误会抛异常，不处理就直接崩：

```python
age = int(input("年龄："))     # 用户输入 "abc" → ValueError，程序直接退出
```

用 `try / except` 兜住：

```python
try:
    age_text = input("年龄：")       # try 中只放可能失败的操作
    age = int(age_text)
    print("明年你", age + 1, "岁")
except ValueError:
    print("请输入数字！")
```

执行逻辑：

1. 先执行 `try`。
2. 如果转换成功，跳过 `except`。
3. 如果 `int()` 抛出 `ValueError`，立即停止剩余的 `try` 代码，跳到匹配的 `except`。
4. `except` 执行结束后，程序继续执行整个结构后面的代码。

不要把整个程序都包进一个巨大 `try`。范围越大，越难判断到底是哪一行失败。

### 完整结构

```python
try:
    num = int(input("请输入除数："))
    result = 100 / num
except ValueError:
    print("这好像不是数字")
except ZeroDivisionError:
    print("除数不能是 0")
except Exception as e:
    print("出了别的错：", e)
else:
    print("一切正常，结果是", result)      # 没出错才执行
finally:
    print("不管怎样都会执行")             # 收尾，比如关文件
```

### 常见异常类型

| 异常 | 什么时候出现 |
| --- | --- |
| `ValueError` | 类型对但值不对，如 `int("abc")` |
| `TypeError` | 类型不对，如 `"a" + 1` |
| `IndexError` | 列表 / 字符串下标越界 |
| `KeyError` | 字典没有这个键 |
| `FileNotFoundError` | 文件不存在 |
| `ZeroDivisionError` | 除以 0 |
| `AttributeError` | 对象没有这个属性 / 方法 |

> 抓异常要**抓具体的类型**（`except ValueError`），别一上来就 `except Exception` 把什么都盖住——那样真正的 bug 会被藏起来，以后更难查。

### 报错信息怎么读

出现 Traceback 时按“从下往上”阅读：

```text
Traceback (most recent call last):
  File "demo.py", line 3, in <module>
    age = int("abc")
ValueError: invalid literal for int() with base 10: 'abc'
```

- 最后一行：异常类型是 `ValueError`，失败的数据是 `'abc'`。
- 倒数第二行：真正失败的是 `int("abc")`。
- 再上一行：失败位置是 `demo.py` 第3行。

先解决最下面指出的第一个明确问题，再重新运行；不要一次改很多地方。

## 五、类与对象（能读懂、能改就够）

先记住一句话：**类是一张图纸，对象是按图纸造出来的东西。**

```python
class Student:
    def __init__(self, name, score):
        # 左边 self.name 是对象长期保存的属性
        # 右边 name 是创建对象时传进来的参数
        self.name = name
        self.score = score

    def is_pass(self):
        # 通过 self 读取“当前这个学生”的分数
        return self.score >= 60

    def introduce(self):
        print(f"我是{self.name}，成绩{self.score}")


# 按图纸造两个对象
s1 = Student("小明", 92)
s2 = Student("小红", 55)

s1.introduce()              # 我是小明，成绩92
print(s1.is_pass())        # True
print(s2.is_pass())        # False
```

三件事必须理解：

1. **`class Student:`** —— 定义类，类名首字母大写。
2. **`__init__`** —— 特殊方法，**创建对象时自动执行**，用来设置初始属性。前后各两个下划线。
3. **`self`** —— 指「当前这个对象自己」。方法里访问自己的属性必须写 `self.xxx`，参数表里第一个位置永远是 `self`（调用时不传它）。

创建 `s1 = Student("小明", 92)` 时可以这样理解：

1. Python 创建一个新的 `Student` 对象。
2. 自动调用 `__init__(s1, "小明", 92)`。
3. `self` 指向 `s1`，所以 `self.name = name` 相当于给 `s1` 保存姓名。
4. 创建结束后，`s1.name` 是 `"小明"`，`s1.score` 是 `92`。

`s1.is_pass()` 调用时也会自动把 `s1` 交给 `self`，所以括号里不用再传 `s1`。

### 直接改属性

```python
s1.score = 95          # 改属性
print(s1.score)        # 95
print(s1.name)         # 小明
```

> 本周**只需要**：能看懂 `class` 长什么样、能造对象、能调方法、能改属性。继承、魔术方法、`@property` 这些**不讲**，以后需要再说。

### 为什么要有类

```python
# 用字典也能存一个学生
student = {"name": "小明", "score": 92}
# 但「判断是否及格」这个逻辑没地方放，只能到处复制
```

类的价值在于：**把数据和处理这些数据的方法绑在一起**。下周 NumPy、后面 PyTorch 里的模型，全都是类。

### 类、对象、属性、方法对照

| 名称 | 本例 | 作用 |
| --- | --- | --- |
| 类 | `Student` | 规定学生对象应该有哪些数据和行为 |
| 对象 | `s1`、`s2` | 根据类创建的具体学生 |
| 属性 | `name`、`score` | 每个对象自己保存的数据 |
| 方法 | `is_pass()`、`introduce()` | 对对象数据执行的操作 |

## 六、本周产出：读 CSV 统计行数

```python
import csv

def count_rows(filename):
    """读 CSV，返回数据行数（不含表头）"""
    count = 0
    with open(filename, "r", encoding="utf-8", newline="") as f:
        reader = csv.DictReader(f)
        for _row in reader:
            count += 1  # 每成功读到一条数据就累计 1
    return count


try:
    n = count_rows("scores.csv")
    print(f"共 {n} 条数据")
except FileNotFoundError:
    print("找不到 scores.csv，请检查文件是否在当前目录")
```

注意这里把上周学的**函数**和这周学的**文件 + 异常**合在了一起，这就是学习曲线往上走的样子。

## 七、常见错误对照表

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `FileNotFoundError` | 路径不对 / 不在当前目录 | 用绝对路径，或先 `print(os.getcwd())` 看在哪 |
| `UnicodeDecodeError` | 没写 `encoding="utf-8"` 或文件是 GBK | 加上 `encoding="utf-8"`；GBK 文件用 `encoding="gbk"` |
| 读完文件后内容是空的 | 用了 `"w"` 打开，把内容清空了 | 读用 `"r"`，写才用 `"w"` |
| 每行末尾多一个空行 | 读出来的行带 `\n`，`print` 又加了一个 | 用 `line.strip()` |
| `NameError: name 'self' is not defined` | 方法里少写了 `self` | `def f(self, ...)` |
| `TypeError: introduce() takes 1 positional argument but 2 were given` | 定义方法时忘了写 `self` | 参数表第一个写 `self` |
| 程序崩了但不知道错在哪 | 没有异常处理 | 看报错最后一行的异常类型和行号 |
| `except` 写了但没兜住 | 异常类型对不上 | 看清报错里的异常名，写对类型 |

### 类与面向对象

```python
# ============================================================
# 第 4 周：面向对象（类）
# 目标：用"类"来组织代码，这是基础阶段的终点
# ============================================================

# ---- 1. 什么是类和对象 ----
# 类 = 模板（设计图）
# 对象 = 根据模板造出来的具体东西（实例）
# 比如："狗"是一个类，"你家那只叫旺财的狗"是一个对象

# ---- 2. 定义一个类 ----
class Dog:
    # __init__ 是构造方法，创建对象时自动调用
    # self 代表"当前这个对象"（必须有，但不传它）
    def __init__(self, name, age):
        self.name = name      # 给对象设置"属性"
        self.age = age

    # 类里的函数叫"方法"，第一个参数必须是 self
    def bark(self):
        print(f"{self.name} 在叫：汪汪！")

    def info(self):
        print(f"{self.name} 今年 {self.age} 岁")

# ---- 3. 创建对象（实例化）----
dog1 = Dog("旺财", 3)    # 自动调用 __init__
dog2 = Dog("小白", 5)

print(dog1.name)         # 访问属性：旺财
dog1.bark()              # 调用方法
dog1.info()

# ---- 4. 综合练习：学生对象 ----
# 本学期只要求掌握属性和普通方法，不展开继承、私有属性和魔法方法
class Student:
    def __init__(self, name, score):
        self.name = name       # 学生姓名
        self.score = score     # 学生成绩

    def is_pass(self):
        """返回是否及格，返回值是 bool。"""
        return self.score >= 60

    def introduce(self):
        """打印当前学生的介绍。"""
        result = "及格" if self.is_pass() else "不及格"
        print(f"学生：{self.name}，成绩：{self.score}，{result}")

students = [
    Student("小明", 90),
    Student("小红", 55),
    Student("小刚", 82),
]

# 列表里保存的是三个 Student 对象，逐个调用它们的方法
for student in students:
    student.introduce()
``` 

### 文件操作与异常

```python
# ============================================================
# 第 4 周：文件操作与异常处理
# 目标：读写文件，以及让程序出错时不崩溃
# ============================================================

# ---- 1. 写文件 ----
# open() 打开文件，'w' 表示写入（会覆盖原内容）
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

# with 语句的好处：用完自动关闭文件，不用手动 close()

# 'a' 表示追加（不覆盖，接着写）
with open("test.txt", "a", encoding="utf-8") as f:
    f.write("追加的一行\n")

# ---- 2. 读文件 ----
# 'r' 表示读取
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()        # 一次性读全部
    print(content)

with open("test.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()     # 读成列表，每行是一个元素
    print(lines)

# 逐行读（最常用，省内存）
with open("test.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())   # strip 去掉每行末尾的换行符

# 打开模式速查：
# 'r' 读  'w' 写(覆盖)  'a' 追加  'b' 二进制  '+' 读写

# ---- 3. 异常处理 ----
# 程序出错时会"抛异常"，如果不处理，程序就崩溃了
# try/except 可以"接住"错误，让程序继续跑

try:
    num = int("abc")    # 这行会出错："abc" 不能转成整数
except ValueError:
    print("转换失败：不是数字")

# 捕获多种异常
try:
    result = 10 / 0     # 除零错误
except ZeroDivisionError:
    print("不能除以零！")
except Exception as e:  # 捕获所有其他异常，e 是错误信息
    print(f"出错了：{e}")

# finally：无论是否出错都会执行
try:
    f = open("不存在.txt", "r")
except FileNotFoundError:
``` 

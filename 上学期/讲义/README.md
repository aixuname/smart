## 学习方法

1. **课前**：把讲义当天的「本周目标」读一遍，知道这周要会什么。
2. **课上**：跟着示例敲，不要复制粘贴。每个代码块都自己跑一遍。
3. **课后**：完成「课堂练习」和「课后作业」，作业提交到课程仓库。
4. **卡住时**：先看讲义末尾的「常见错误」，大部分问题都能在那里找到。

## 三点提醒

- 讲义里的代码都是能直接跑的，**报错了先检查缩进和引号**。
- 第 5 周是概念课，重点是理解 Agent 怎么工作，不是背命令。
- 第 7 周内容最密（Pandas 两周并一周），跟不上就按「自查清单」逐项补，不要硬跟。
- 每周作业都必须能跑出结果，看得懂不算学会。

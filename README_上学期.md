## 在 VS Code 中学习

1. 按照章节顺序打开课程文件。
2. 阅读代码和注释，尝试修改示例中的数据。
3. 点击 VS Code 右上角的“运行 Python 文件”按钮查看结果。
4. 完成一章后，尝试不看示例重新写一遍核心代码。

## 学习目标

完成上学期课程后，你应该能够：

- 使用变量、字符串和常用数据结构处理数据。
- 使用条件判断和循环解决基础问题。
- 编写并调用函数和模块。
- 进行基础文件读写和异常处理。
- 理解类与对象的基本概念。
- 使用 NumPy 进行基础数组计算。

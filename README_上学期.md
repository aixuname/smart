## Python 基础压缩原则

八周时间有限，基础内容只保留「够用」的部分，其余转自学清单：

- **数据结构**：列表、字典必须熟练；元组、集合认识即可。
- **循环**：`for` 必须熟练；`while` 认识即可；嵌套循环少讲。
- **函数**：`def`、参数、`return` 必须会；默认参数、递归不讲。
- **模块与包**：会用 `import` 和第三方库；自己写包不讲。
- **文件与异常**：基本读写和 `try / except`；自定义异常类、`with` 的深入用法不讲。
- **类与对象**：`class` + `__init__` 能读能改；继承、魔术方法、属性装饰器全不讲。
- **字符串**：只挑 `strip / split / replace / find / upper` 五个。

## 数学穿插安排

不单独设数学课，每次课前用 10 分钟讲直觉，不做证明：

- 第 5 周：向量与矩阵乘法（用 NumPy 现场演示）。
- 第 7 周：均值、方差、分布（用真实数据算一遍）。
- 第 8 周：讲「导数就是斜率、梯度就是该往哪个方向调」，为下学期铺垫。

## 第 8 周：AI 编程工具配置

这一周不写新语法，目标是让每个人电脑上真正跑通一套 AI 编程工具。

### 涉及的工具

| 工具 | 作用 |
| --- | --- |
| Node.js（LTS） | 前置依赖，Codex CLI 通过 npm 安装 |
| Codex CLI | 命令行的 AI 编程助手，能读代码、改代码、执行命令 |
| Claude Code | 同类的命令行 AI 编程工具 |
| [CC Switch](https://github.com/farion1231/cc-switch) | 跨平台桌面应用，统一管理 Claude Code / Codex / Gemini CLI 等工具的供应商配置，内置预设，一键切换 |

### 课前准备（装机清单）

**这一条必须提前三天做**，课上只做配置和验证，不现场装环境。

- [ ] 安装 Node.js（LTS 版本），能运行 `node -v` 和 `npm -v`
- [ ] 配置 npm 国内镜像：`npm config set registry https://registry.npmmirror.com`
- [ ] 安装 Codex CLI：`npm install -g @openai/codex`，能运行 `codex --version`
- [ ] 下载并安装 CC Switch（GitHub Releases 或官网）
- [ ] 准备一个可用的 API Key（课上统一发放或自备）

### 课上流程

每一步验证通过再往下走：

1. 验证 Node 环境：`node -v`、`npm -v`
2. 打开 CC Switch，顶部应用切换器选中 **Codex**
3. 点击 `+` 添加供应商：选预设 → 填入 API Key → 添加 → 启用
4. 打开终端进入项目目录，运行 `codex`，先让它「解释这个文件在做什么」
5. 切到 **Claude**，用同样的方式再配一遍（CC Switch 支持热重载，切换后不必重启终端）
6. 讲心智模型：**它是会读写文件的同事，不是搜索引擎**——先让它读、再让它改、小步验证、用 Git 兜底
7. 实战：用它给第 7 周的图表加标题、改成按周汇总，并让它解释一个真实报错

### 安全与成本（必讲）

- API Key **不能**进仓库、不能发群里、不能截图外传。
- 每一轮对话都在消耗 Token、都在花钱，小问题用聊天窗口问，大改造才用命令行。
- **改之前先 `git commit`**，改坏了直接 `git checkout .` 回退。
- 不要相信它说「已经修好了」，一定要自己跑一遍看结果。
- 不要给它整个磁盘的权限，只在具体项目目录里使用。

### 不展开的内容

CC Switch 的 MCP 管理、本地代理与故障转移、WebDAV 云同步、技能管理等进阶功能一句话带过，让大家以后自己探索。零基础阶段讲多了记不住。

## 学习建议

1. 每周的产物一定要自己独立跑通一遍，不要只看得懂。
2. 卡住超过 30 分钟就先记录报错、跳过，课后一起解决。
3. 每周学完，尝试不看示例重新写一遍核心代码。
4. 第 8 周配置 AI 工具时，先用手上的小项目试，不要一上来就丢给它一整个陌生工程。

## 学习目标

完成上学期课程后，你应该能够：

- 使用变量、字符串和常用数据结构处理数据。
- 使用条件判断和循环解决基础问题。
- 编写并调用函数和模块。
- 进行基础文件读写和异常处理。
- 理解类与对象的基本概念。
- 使用 NumPy 进行基础数组运算。
- 读懂一份 CSV，做清洗、分组统计并画出图表。
- 在自己的电脑上配好 AI 编程工具，并安全地用它辅助写代码。
